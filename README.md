# Generative Models Atlas | 生成模型图谱

A curated collection of notes on influential generative modeling papers, focusing on their core ideas, methodological insights, and practical applications.

精选生成模型领域的代表性论文，围绕核心思想、方法原理与实际应用进行解读和分析。

## About | 项目简介

This repository documents selected papers on generative models. Each paper is analyzed in an independent Markdown file, with an emphasis on understanding the underlying methods and exploring their potential applications.

本仓库用于整理和解读生成模型领域的精选论文。每篇论文以独立的 Markdown 文件进行记录，重点关注方法原理的理解与潜在应用的分析。

## Notes | 论文笔记

Paper notes will be added and updated progressively as the collection evolves.

论文笔记将随着知识积累逐步补充和更新。
